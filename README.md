## Introduction
Hello! I m Farwa Zafar from Pakistan I am making this project whihc is earthQuick detector which will detect the vibration using vibration sensor and then it will alert us with the help of sound and led light showing the danger
## Functionalities
* Vibration detction: when vibration happens the sensor will detect it in the form of Earthquick
* Alert Sound: buzzer will make sound when vibration occurs
* Led On/Off: when earthquick come the red led will be on showing the danger and when it is safe it will be off

## Components used in This Project
Esp32-S3 a mictrocontroller whihc controls all the functions , vibration sensor which detects the vibration, buzzer which will produce soound hen the vibartion hppens,
red led hich will be on when vibration happen, and resistor which protect the led to not be burned , and also a oled display which will show the alerts and a breadboard
